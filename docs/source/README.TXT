To developers:
The website is built with Quarto, and the Python API reference is generated by quartodoc.
Install Quarto from https://quarto.org/docs/get-started/ and install the Python dependency with:

    pip install -r docs/requirements.txt

Build the website from the repository root with:

    docs/build_docs.sh

For a live preview, run `quarto preview` from `docs/source`.
Quartodoc generates API Markdown pages under `source/reference` during the build.
The quartodoc configuration uses its `sphinx` docstring parser for the project's Markdown docstrings; Sphinx itself is not used.
